## 🛠️ Techniques Covered
This project focuses on the following core array patterns:
- **Two Pointers:** Used for searching pairs or reversing arrays.
- **Sliding Window:** Used for sub-array problems (fixed and variable size).
- **Prefix Sum:** Pre-calculating sums to answer range queries in $O(1)$.
- **Hashing:** Using HashMaps/Sets for frequency counting and $O(1)$ lookups.
- **Sorting:** Implementing and leveraging QuickSort, MergeSort, and built-in sorting.
- **Binary Search:** Searching in sorted arrays in $O(\log n)$.
